##2025_sc_iso_paper
	Analysis suite accompanying the manuscript "Single cell long read sequencing of the experience-induced transcriptome"
	--Sheridan Cavalier 2025

## Description
Scripts for processing ONT reads generated by 10X Genomics and R2C2 library preparation.
# READ PROCESSING AND SORTING
1. Concatameric ONT reads generated by R2C2 are filtered and deconcatenated into consensus reads.
2. 10X barcodes and UMI sequences are determined for each consensus read that has the appropriate 10X adapters.
3. Barcodes are demultiplexed first by exact matching to 10X whitelist, a barcode shortlist is generated from these matched barcodes.
	Reads that don't have exact barcode matches are categorized as belonging to a barcode in the shortlist if L < 3.
4. Reads are mapped to the given reference genome with Minimap2 and assigned to a genomic feature with FeatureCounts.
	Reads with the same barcode that map to the same genomic feature are collapsed if their UMIs are within L < 2.
5. Barcode rank is determined by UMI count and a percentile-based strategy is used to determine cell barcodes above background. 
# GENERATING GENE COUNT MATRIX
6. Reads within each barcode are mapped to the given reference genome with Minimap2. 
	Each read is assigned to a genomic feature with FeatureCounts based on its primary alignment.
7. Gene counts per barcode are formatted for Seurat into three files: 
	barcodes.tsv, features.tsv, and matrix.mtx
# GENERATING ISOFORM COUNT MATRIX
8. Reads within each barcode are mapped to the given reference transcriptome with Minimap2. 
9. Isoform quantification with Salmon is performed on resulting transcriptome alignment files. 
10. Integer count values (raw) reported by Salmon for each isoform are recorded for each barcode. 
	Isoform counts per barcode are formatted for Seurat input.

##Installation
conda env create -n sc_iso -f environment.yaml
conda activate sc_iso
pip install ./conk-master

10X barcode whitelist (not included): 3M-february-2018.txt ships with 10X Cell Ranger
	(cellranger-x.y.z/lib/python/cellranger/barcodes/3M-february-2018.txt.gz). Gunzip it before use with detBarcodes.py.

Optional config file (-c): by default all executables (minimap2, racon, blat, samtools, featureCounts, salmon) are taken from $PATH.
	To use other copies, pass -c with a tab-separated file of program name and path, one per line, e.g.
	minimap2	/path/to/minimap2
	racon	/path/to/racon

##Usage (run in order listed)
1. C3POa_sc.py
	Performs C3POa on Nanopore reads. 
	C3POa uses splint alignment to determine subread boundaries on concatemeric R2C2 reads. 
	Subreads are aligned and polished with Racon into resulting consensus reads. Use C3POa_multi.py for files > 5M reads. 
 
./C3POa_sc.py  -r input.fastq -s files/R2C2_splint.fasta -o output/path/ -n threads

Outputs: R2C2_Consensus.fasta, R2C2_Subreads.fastq

For files > 5M reads, C3POa_multi.py splits the input into 5M-read chunks, runs C3POa_sc.py on each and concatenates the results:

./C3POa_multi.py -i input.fastq -s files/R2C2_splint.fasta -o output/path/ -n threads

Outputs: <input name>_R2C2_Consensus.fasta

2. C3POa_postprocessing.py
	Filters and orients consensus reads 5' to 3' via 10X adapter alignment.
	Creates separate barcode/UMI file storing the last 28bp of each read.
	This script can be used on any barcoded long reads with universal adapters if sequences are provided.

./C3POa_postprocessing.py -i R2C2_Consensus.fasta -a files/10X_adapters.fasta -o output/path/ -n threads -t -b

Outputs: R2C2_full_length_consensus_reads.fasta, R2C2_full_length_consensus_reads_10X_sequences.fasta

3. detBarcodes.py
	Reads with an exact match to a barcode in the provided 10X whitelist are counted. 
	Barcode shortlist is generated from barcodes with exact matches.
	Typically 85+% of reads from postprocessing have exact matches. 

./detBarcodes.py -i R2C2_full_length_consensus_reads_10X_sequences.fasta -w 3M-february-2018.txt -o output/path/

Outputs: all_bcs.fasta

4. Demux_by_kmer.py
	Reads without exact barcode matches are assigned to a barcode in the shortlist if L < 3. 
  
./Demux_by_kmer.py -i R2C2_full_length_consensus_reads_10X_sequences.fasta -n all_bcs.fasta -o output/path/

Outputs: allbckmer_demuxed.fasta

5. make_barcode_files.py
	Aggregates reads into fasta files by barcode and returns a list of barcodes with associated UMI counts (non collapsed).

./make_barcode_files.py -r R2C2_full_length_consensus_reads.fasta -b all_bcs.fasta -k allbckmer_demuxed.fasta -o output/path/

Outputs: /demuxed/ directory, bcGuide.txt

6. MapAssignSort.py
	Maps reads to reference genome. Reads are assigned to the genomic feature matching their primary alignment (FeatureCounts).
	Reads in each barcode file are sorted by gene feature for quick UMI collapsing. 

./MapAssignSort.py -p /demuxed/ -g Mus_musculus.GRCm39.103.gtf -r GRCm39.primary_assembly.genome.fa -o output/path

Outputs: /assignedreads/ directory

7. UMI_Collapse.py
	Reads with the same barcode that map to the same genomic feature are collapsed if UMIs L < 2.

./UMI_Collapse_2022/UMI_Collapse.py -a /assignedreads/ -d /demuxed/ -o output/path/

Outputs: /demuxed_final/ directory


8. UMIsBarcodes.py
	Barcodes are ranked by number of UMIs. Barcodes with a UMI count at least 1/10 that of the barcode in the 99th percentile are considered cells.
	An extra ten percent of targeted cells are included. Returns a reordered demuxed directory and barcode list ranked by collapsed UMI number.

./UMIsBarcodes.py -p /demuxed_final/ -t #cells targeted by 10X -b bcGuide.txt -o output/path/

Outputs: /demuxed_sorted/ directory, BcGuide_reordered.txt

9. map_cells_genome.py
	Maps reads to reference genome and saves cell sam files in a directory for FeatureCounts.
	Runs FeatureCounts on cell sam directory to generate file storing features per cell. 

./map_cells_genome.py -p /demuxed_sorted/ -a Mus_musculus.GRCm39.103.gtf -r GRCm39.primary_assembly.genome.fa -o output/path/

Outputs: /cellsams/ directory, allcellsmtx_featureCount.txt

10. make_seurat_input_genome.py 
	Generates barcodes.tsv, features.tsv, and matrix.mtx files from genome mapping and feature quant. For use in Seurat and other applications.

./make_seurat_input_genome.py -b BcGuide_reordered.txt -e allcellsmtx_featureCount.txt -a Mus_musculus.GRCm39.103.gtf -o output/path/

Outputs: barcodes.tsv, features.tsv, matrix.mtx

11. map_cells_txtome.py
        Maps reads to reference transcriptome and saves cell sam files in a directory for Salmon.
        Runs Salmon on cell sams directory to generate quant files storing transcript counts per cell. 

./map_cells_txtome.py -p /demuxed_sorted/ -r gencode.vM32.transcripts.fa -o output/path/

Outputs: /cellsams_tx/ and /cell_salmon_quants/ directories

12. make_seurat_input_txtome.py
        Generates barcodes.tsv, features.tsv, and matrix.mtx files from transcriptome mapping and Salmon quant. For use in Seurat and other applications.

./make_seurat_input_txtome.py -p /cell_salmon_quants/ -o output/path/

Outputs: /Seurat_Input/ directory with barcodes.tsv.gz, features.tsv.gz, matrix.mtx.gz (plain text despite the .gz names)
